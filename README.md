# 작은 어항 구피 가게

구피를 교배해 새로운 품종을 모으고, 전시 어항을 꾸며 손님을 받는 모바일 육성 게임입니다.

## 파일
- `index.html` — 게임 본체(한 파일). 휴대폰 브라우저에서 바로 열립니다.
- `show_demo.html` — 전시 어항(모래 폭포 · 떠 있는 섬) 감상 데모

## 주요 시스템
- 멘델 유전: 꼬리 · 색 · 무늬 · 알비노 · 플래티넘 · 메탈 · 빅도살 · 지느러미, 대를 이을수록 고정되는 형질
- 1자 교배 어항(시간이 흐르고 새끼를 낳음)과 3자 전시 어항(시간이 멈추고 늙지 않음, 테마 · 장치)
- 번식통: 목표에 맞는 짝 추천, 발현 확률 올리기, 분리망 건너편 치어칸
- 사진첩 239칸, 새 색 단계별 해금, 사진첩 품종 다시 데려오기
- 튜토리얼, ❔ 도움말 모드, 처음 누를 때 설명

## 저장
브라우저 저장소(localStorage)에 저장됩니다. Claude 아티팩트에서 열면 클라우드 저장도 함께 사용합니다.

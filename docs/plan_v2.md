# 구피 가게 v2 설계 (11/25 확정안 · D 검토 대기)

핵심 루프 한 줄: **의뢰로 목표를 받는다 → 족보로 길을 찾는다 → 번식한다 → 결과 공개 → 사진첩 기록 → 전시관에 영구 전시**

## 벤치마킹 요약
- 동물의 숲 박물관: 기증하면 영구 전시, 모아 둔 것이 한 공간에 모여 보이는 만족. → 전시관.
- 드래곤 시티 드래곤 북: 컬렉션을 완성하면 프리미엄 재화 보상. → 사진첩 챕터 보상.
- 네코 아츠메: 아무것도 죽지 않음, 압박 없음, 사진첩(Catbook) 수집. → 전시관은 시간 정지.
- 캣츠 앤 수프·방치형 게임: 수익은 선택형 보상 광고(부스트·재화). 과하면 리뷰에서 불만. → 광고는 선택형만, 하루 상한.
- 피쉬 타이쿤: 7마리 마법 물고기라는 고정 목표 + 유전 퍼즐. → 의뢰 10단계.

## 1. 의뢰 스테이지 (수습 이후 GOALS를 대체)
| # | 손님 | 목표 | 배우는 것 | 선물 종어 | 기준 세대 |
|---|---|---|---|---|---|
| 1 | 동네 꼬마 | 블루 델타 | 우성 꼬리 | - | 1 |
| 2 | 카페 사장 | 레드 코브라 | 우성 무늬 합치기 | - | 1 |
| 3 | 과학실 선생님 | 옐로 | 열성 색 | 옐로 숨긴 암컷 | 2 |
| 4 | 사진작가 | 알비노 | 숨은 형질 | 알비노 숨긴 수컷 | 2 |

- 의뢰가 오면 족보가 그 목표로 열린다(목표 고민 제거).
- 받는 순간 이미 조건 맞는 구피가 있으면 즉시 완료 가능.
- 기준 세대 이하로 끝내면 보너스(별점 없음: 운 요소 때문).
- 10단계 뒤: 랜덤 의뢰가 사진첩 미발견 모습 위주로 계속 생성(엔드리스). 2부는 재미 확인 후.

## 2. 전시관 (전시 어항 개편)
- 사진첩에서 **내 가게에서 태어난(번식한) 모습만** 골라 넣는다. 산 구피·선물 종어의 모습은 번식으로 다시 얻어야 전시 가능.
- 전시 구피 = 모형: 번식·판매·의뢰·이동·족보 계산에서 전부 제외. 시간 정지(먹이·늙음 없음).
- 수입: 전시관 손님 수입 = 전시 모습의 희귀도 합, **상한 있음**(후반 돈 폭주 방지).
- 기존 세이브: 전시 어항의 진짜 구피는 일반 어항(자리 없으면 보육통)으로 돌려보내고, 그 모습은 전시관에 등록(내가 번식한 모습이면).

## 3. 사진첩 챕터
- 1장 기본색 / 2장 숨은 색 / 3장 특별 형질(지금 page 구분 사용). 사진첩 등록도 '내가 번식한 모습' 기준 표시(산 것은 '구매' 표시).
- 70% 달성 보상: 1장 번식통 +1 / 2장 전시관 테마 / 3장 전설 의뢰 해금.

## 4. 정리(빼기)
- 뽑기: 없앰(돈으로 수집 건너뛰기 방지). 대신 상점 '종어' 칸(의뢰에 필요한 숨은 유전자 보유, 비쌈) = 큰 지출처.
- 수습 이후 숫자 목표(의뢰 n개·사진첩 n개): 의뢰 스테이지로 대체.
- 남김: 랜덤 의뢰(돈벌이), 판매, 목표 선별, 번식통 유지비, 꾸미기.

## 5. 광고 자리(선택형만, 하루 상한)
- 의뢰 완료 보상 2배 / 선물 종어 하나 더 / 치어 바로 어른 / 전시관 특별 배경(하루 체험).
- 강제 광고 없음. 하루 보상형 광고 상한 두기(과하면 캣츠 앤 수프 리뷰처럼 불만).

## 6. 연출
- 의뢰 완료: 손님 반응 + 보낸 구피 '추억 사진' → 전시관 자동 등록 + 다음 손님 등장.
- 결과 공개: 바구니(새끼 묶음) 열기는 2차 후보.

## 7. 검증
- 지인 3~5명: 의뢰 2번째를 스스로 시작하는지, 의뢰 3(열성)에서 막히는지, 하루 플레이 시간.
- 자동 시뮬: 의뢰별 평균 소요 세대·실시간(×1) 측정 → 선물·기준 세대 조정.

## 구현 순서(새 채팅)
1) 전시관 모형화 + 번식 출처 기록(bred 표시, 저장 '추가만') 2) 의뢰 스테이지 10개 + 선물 종어 3) 챕터 보상 4) 뽑기 제거·종어 상점 5) 광고 자리 6) 시뮬·회귀 테스트·3빌드 배포
